# 赶得上 · 公交通勤出门提醒

> 按你所在的位置，算出每天几点必须出门赶公交。

在线演示（已发布）：https://4mavggytu84w4.doubao.link/app/app_17j0udya6yb

## 它怎么算

1. 读取实时定位（拿不到就退化成「在地图上手动点选我的位置」）
2. 用 OSRM 公共步行路由算走到上车站的真实时间；服务不可用时按直线距离 × 1.3 估算，并在界面上标注「直线估算」
3. 从你填的班次到站时刻里，挑出还赶得上的那一班
4. 出门时间 = 班次到站时刻 − 步行时间 − 预留缓冲
5. 到点全屏提醒 + 响铃 + 系统通知，界面变红并显示「现在出发」

## 文件

```
index.html   页面结构
style.css    样式（站牌 / 时刻板风格 + 动效）
app.js       全部逻辑：定位、步行路线、班次推算、提醒
```

三个文件放在同一目录，直接用浏览器打开 `index.html` 即可，不需要构建。

## 数据说明（重要）

- 到站时刻来自**你自己填的时刻表**，不是公交车的实时定位。厦门公交的实时车辆位置没有免费公开接口，所以这里用时刻推算，界面上也写明了这一点。
- 地图瓦片用高德栅格底图；底图是 GCJ02，浏览器定位是 WGS84，`app.js` 里做了双向换算，否则标记会偏。
- 步行路线走 OpenStreetMap 的 OSRM 公共步行服务；站名反查用 Nominatim。
- 所有设置存在浏览器 localStorage，不上传服务器。

## 技术

原生 JS + Leaflet 1.9.4，无构建、无后端、无 API Key。字体走自托管镜像，瓦片 / 路由 / 反查都是公开服务。

## 界面

右侧做成公交站牌 / 时刻板的样式：深绿路线牌、等宽数字倒计时、等待→步行→缓冲的时间轴、后续班次胶囊。动效只放在有意义的地方（数字翻位、时间轴推进、状态变色、路线流动虚线），并且尊重系统的「减弱动态效果」。

## 已知边界

- 实时性取决于你填的时刻表是否准确；班次变动需要手动更新。
- 步行时间是公开路由服务的结果，路口、高架等场景可能与实际有出入。
- 页面需要联网加载地图与字体；离线时只剩估算与倒计时。
